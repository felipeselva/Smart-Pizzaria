# Smart-Pizzaria
O SmartPizzaria AI é um aplicativo completo para gestão de pizzarias, unindo automação, experiência do cliente e inteligência artificial em uma única plataforma.  O sistema permite que clientes façam pedidos de maneira rápida e intuitiva, enquanto a equipe da pizzaria conta com ferramentas inteligentes para otimizar produção, atendimento e tomada de decisões.
